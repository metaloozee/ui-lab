# When motion feels wrong

Reproduce it first. Sample it with `scripts/sample-frames.mjs`, slow it with Inspect's Speed at ¼×, and find the first wrong frame. Fix why it happens, then look for the same cause elsewhere.

| What you see                                    | Likely cause                                                                                                      | Fix                                                                                  |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Jump on the first frame                         | The start was read after the new state changed layout, such as an arriving panel already stretching its container | Measure what was resting, before or apart from what's arriving                       |
| Freeze, then most of the move in one frame      | Slow content mounted by the same click, so the spring's clock ran during the freeze                               | Mount it ahead of time, once the surrounding motion has finished                     |
| Jump when reversing                             | The morph restarted from a stored end state                                                                       | Start from the live size and the current fades                                       |
| Snap on the last frame                          | A pixel target differs from the resting CSS, or resting content was still settling                                | Read the resting size every frame, then hand back to CSS at rest                     |
| One-frame flash back to the old size at the end | Inline size was released before React removed the old view, so both views stretch the container                   | Remove the old view inside `flushSync`, then release the size                        |
| Surface swells before shrinking                 | The close target is wider for now, such as with a picker open                                                     | Clamp the close target to the starting width                                         |
| Overshoot, then snap back, under a scale        | `"auto"` as a motion target reads the visual size                                                                 | Measure `offsetHeight` or `offsetWidth` and animate to pixels                        |
| Height lands late or lags its child             | Two measured-height animations are stacked                                                                        | Spring only the element that toggled, and snap the wrapper                           |
| Content is sliced by the edge                   | Opacity and height run together                                                                                   | Let opacity lead, or let content wait until there's room                             |
| Parts drift apart in mid-flight                 | Separate animations, or a change listener a frame behind                                                          | Derive every part from one progress value                                            |
| Exit never finishes on a busy page              | The effect depends on a callback that changes every render, such as `safeToRemove`                                | Read it through a ref, and depend only on the state                                  |
| A tooltip or hover lights up by itself          | A control slid under a resting cursor                                                                             | Ignore the pointer until a real `pointermove`, as `useSurfaceMorph` does             |
| Highlight slides in from another row            | An overlay mounted before measuring finished                                                                      | Render `FluidHoverHighlight`, or gate on `isMeasured`                                |
| Highlight blinks off between rows               | A gap between rows                                                                                                | Make rows touch, or use `nearest: true`                                              |
| Highlight or ring sits a fraction off           | Fractional layout above the rows                                                                                  | Round the height above them                                                          |
| Highlight draws over or under the wrong layer   | A mask, clip-path, or filter wrapper paints as one block                                                          | Render the overlay inside that wrapper                                               |
| Neighbors shift when text gets heavier          | No reserved width                                                                                                 | Stack an invisible heavier copy in the same cell                                     |
| Label sits high when selected                   | The hidden width copy is untrimmed                                                                                | Give it the same `text-box` trim as the label                                        |
| Inspect's Feel or Speed doesn't change it       | A hand-written duration, a module-level copy, or an untokened CSS transition                                      | Read `spring` when the animation starts, or use `--spring-*`                         |
| Escape closes two things at once                | React rerenders between listeners, so a later handler sees new state                                              | `preventDefault` in the inner handler, and check `defaultPrevented` in the outer one |
| Canvas shortcuts stop while a panel is open     | Focus landed on the panel                                                                                         | Mark the panel with `data-focus-landing`, so shortcuts still apply                   |
| Stutter only on the first frame                 | Late layer promotion                                                                                              | Add `will-change` naming that property, and re-check `position: fixed` children      |
| Stutter throughout                              | Layout work every frame, or a broad `transition`                                                                  | Name the properties, and move what you can to `transform`                            |
| Reduced motion still moves something            | Width, height, `filter`, or a loop that the config doesn't cover                                                  | Gate it with `useReducedMotionConfig()`                                              |
| Every color smears on a theme switch            | Color transitions all fire together                                                                               | Suppress transitions for the flip                                                    |
